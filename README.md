# RecruitGen AI

A cross-platform Flutter application designed for executive recruiters to generate highly tailored, professional LinkedIn outreach messages based on precise constraints and candidate profiles.

## Features
- Input fields for Candidate Profile and Job Details
- Combines two specific prompt structures (Executive Recruiter & ContactOut concise reach-out)
- Generates a merged, concise, and realistic message with a strong hook
- Keeps messages under 120 words with targeted references

## Tech Stack
- Framework: Flutter
- Language: Dart
- Platforms: Web, iOS, Android, macOS, Windows, Linux

## Setup
1. Ensure Flutter is installed.
2. Clone the repository.
3. Run `flutter pub get`.
4. Run `flutter run`.
